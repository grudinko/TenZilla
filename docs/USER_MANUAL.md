# Инструкция по работе с системой TenZilla

TenZilla — система управления на базе ESP32-S3: тензодатчик (весы NAU7802), энкодер перемещения, двигатель, сенсорный дисплей, Wi‑Fi и веб‑интерфейс. Документ описывает работу с панелью на устройстве и через веб.

---

## 1. Обзор интерфейса

### 1.1 Экраны на дисплее

Экраны переключаются **одной кнопкой** (короткое нажатие — следующий экран, длинное — меню действий).

| № | Экран | Назначение |
|---|--------|------------|
| 0 | Заставка (Splash) | Показ при включении (~3 с), затем переход на главный экран |
| 1 | **Главный (Сжатие)** | Текущая сила (Н), максимум за сессию, прогресс до лимита, график силы |
| 2 | **Разрыв** | Текущая сила, максимум, абсолютное (MOV) и рабочее (WRK) перемещение |
| 3 | **Wi‑Fi** | Статус сети (Connected / AP Mode), SSID, IP, уровень сигнала, кол-во клиентов |
| 4 | **Настройки весов** | Текущий вес, RAW, фактор калибровки, нулевая/вторая точка, шум, макс. вес |
| 5 | **Настройки двигателя** | Состояние мотора, направление, лимиты, энкодер |
| 6 | **Прочие настройки** | Пороги программ (сжатие/разрыв), настройки программы |
| 7 | **История измерений** | Список сохранённых измерений с датой и временем |
| 8 | **Меню подтверждения** | START / RESET MOV / RESET ZERO / EXIT (см. ниже) |

В верхней части экранов 1–7 отображаются: уровень Wi‑Fi (dBm), FPS, загрузка CPU. Внизу — дата/время (при синхронизации NTP) и время работы (Uptime).

### 1.2 Кнопка и навигация

- **Одна физическая кнопка** (пин задаётся в `TenZillaPins.h`).
- **Короткое нажатие** (менее ~2 с): переход на **следующий экран** (1 → 2 → … → 7 → 1). Во время работы программы короткое нажатие не переключает экран.
- **Длинное нажатие** (~2 с и более):
  - На экранах **1 (Главный)** или **2 (Разрыв)** — открывается **меню подтверждения** (START, RESET MOV, RESET ZERO, EXIT).
  - На экранах **3–7** — то же меню, но **без кнопки START** (только RESET MOV, RESET ZERO, EXIT).
  - **Во время работы программы** — **остановка программы** и короткий звуковой сигнал.

В меню подтверждения:
- **Короткие нажатия** переключают подсвеченный пункт (циклически).
- **Длинное нажатие** по выбранному пункту выполняет действие и закрывает меню.

### 1.3 Меню подтверждения (экран 8)

- **START** (только на экранах 1 и 2) — запуск программы:
  - С экрана 1 — **программа «Сжатие»**.
  - С экрана 2 — **программа «Разрыв»**.
- **RESET MOV** — сброс счётчика перемещения (абсолютное перемещение энкодера обнуляется).
- **RESET ZERO** — установка нуля весов по текущему показанию (тарирование).
- **EXIT** — выход из меню без действий.

## 2. Программы «Сжатие» и «Разрыв»

### 2.1 Запуск и остановка

- **Запуск:** на экране 1 или 2 — длинное нажатие кнопки → меню → выбрать **START** → длинное нажатие для подтверждения.
- **Остановка:** в любой момент — **длинное нажатие кнопки** (программа останавливается, двигатель выключается, короткий гудок).

Через веб: вкладка «Программа» — кнопки «Запустить программу СЖАТИЕ» / «Запустить программу РАЗРЫВ» и «Остановить программу».

### 2.2 Программа «Сжатие»

1. Ожидание 3 с.
2. Двигатель опускает образец вниз до начала роста силы (выше порога начала сжатия).
3. Начинается накопление **рабочего перемещения** (WRK) по энкодеру.
4. Программа завершается при достижении **целевого рабочего перемещения** (мм) или при остановке пользователем.

Настройки (веб или экран «Прочие настройки»): порог начала сжатия (Н), целевое перемещение (мм).

### 2.3 Программа «Разрыв»

1. Ожидание 3 с.
2. Двигатель опускает образец вниз до начала роста силы.
3. Идёт отслеживание максимума силы и текущей силы.
4. Программа завершается при **падении силы на заданный процент** от максимума (порог разрыва) или при остановке пользователем.

Настройка: порог падения (%) — в «Прочие настройки» или через веб.

## 3. Весы и калибровка

### 3.1 Что отображается

- **Главный экран / Разрыв:** текущая сила (Н), максимум за сессию, прогресс до установленного лимита (Н).
- **Настройки весов:** текущий вес (Н), RAW АЦП, фактор калибровки, RAW нулевой точки, значение второй точки (Н и RAW), уровень шума (%), максимальный вес (лимит).

Сброс максимума на экране: через веб (кнопки сброса максимума для главного/разрыва) или через API.

### 3.2 Тарирование (ноль)

- **С дисплея:** меню подтверждения → **RESET ZERO** → длинное нажатие. Ноль устанавливается по текущему усреднённому показанию.
- **Через веб:** раздел калибровки — установка нулевой точки (API `/api/calibration/set-zero` или форма в веб-интерфейсе).

### 3.3 Калибровка по двум точкам

Калибровка выполняется **через веб-интерфейс** (пошаговая калибровка):

1. **Старт калибровки** — сброс состояния калибровки.
2. **Нулевая точка** — без нагрузки зафиксировать ноль (или снять текущее значение как ноль).
3. **Вторая точка** — приложить эталонный груз (известная сила в Н), зафиксировать точку.

Также доступны: установка порога шума (%), настройки производительности чтения (интервал опроса, таймаут NAU7802, скорость I2C) — через веб API или соответствующие разделы веб-интерфейса.

## 4. Двигатель и энкодер

### 4.1 Управление мотором

- В программах «Сжатие» и «Разрыв» двигатель управляется автоматически.
- **Вручную:** через веб — кнопки «Вверх», «Вниз», «Стоп» (API: `/api/motor/up`, `/api/motor/down`, `/api/motor/stop`).

На экране «Настройки двигателя» отображаются: состояние (стоп/вверх/вниз), направление, настройки энкодера и лимитов.

### 4.2 Перемещение (MOV) и сброс

- **MOV** — абсолютное перемещение по энкодеру (мм), считается от последнего сброса.
- **Сброс MOV:** меню подтверждения → **RESET MOV** → длинное нажатие. Либо через веб (соответствующий API).

### 4.3 Энкодер

- Шаг энкодера (мм/импульс), минимум/максимум, режим «только B» настраиваются через веб (раздел энкодера) или API.
- Подробности по Hall-энкодеру и пинам — в [ENCODER_HALL.md](../ENCODER_HALL.md) и [TenZillaPins.h](../src/TenZillaPins.h).

### 4.4 Ограничения перемещения

- Включены по умолчанию: двигатель не выходит за заданные пределы по энкодеру.
- **Временное отключение** (например, для настройки): через веб (API ограничений) с вводом пин-кода. После отключения рекомендуется снова включить ограничения.

## 5. Wi‑Fi и веб-интерфейс

### 5.1 Подключение к устройству

- Если устройство подключилось к вашей сети (STA) — откройте в браузере **IP-адрес** (показан на экране «Wi‑Fi»). Порт 80.
- Если устройство в режиме точки доступа (AP Mode) — подключитесь к Wi‑Fi **TenZilla_AP** (пароль см. в конфигурации), затем в браузере откройте, как правило, **http://192.168.4.1**.

### 5.2 Основные разделы веб-интерфейса

- **Главная (/)** — статус, быстрые действия, ссылки на разделы.
- **Конфигурация** — SSID/пароль Wi‑Fi, сохранение настроек, сброс, перезагрузка.
- **Данные весов** — текущая сила, RAW, статус (например, `/api/scale`).
- **Мотор** — вверх/вниз/стоп, сброс счётчика, ограничения.
- **Калибровка** — пошаговая калибровка, ноль, вторая точка, порог шума, производительность NAU7802/I2C.
- **Программа** — пороги и целевое перемещение, запуск/остановка «Сжатие» и «Разрыв».
- **NTP** — сервер времени, интервал синхронизации, часовой пояс.
- **Telegram** — токен бота, Chat ID, включение/выключение, тест отправки.
- **История измерений** — просмотр сохранённых записей (`/api/measurements`).
- **Обновление прошивки (OTA)** — страница `/update`: загрузка бинарного файла прошивки (при включённой OTA и корректной схеме разделов).

Количество одновременных веб-подключений ограничено (настраивается в конфигурации).

---

## 6. Время и NTP

- Дата и время на дисплее берутся из NTP после успешной синхронизации.
- Настройки: сервер NTP, интервал синхронизации, часовой пояс — через веб (раздел NTP) или API (`/api/ntp`, `/api/ntp/server`, `/api/ntp/interval`, `/api/ntp/timezone`).
- Если NTP не синхронизирован, внизу экрана отображается «NTP: Not synced».

---

## 7. Telegram

- В разделе «Telegram» веб-интерфейса задаются: токен бота, Chat ID, включаются уведомления (старт системы, результаты программ, перегрузка/лимиты, ручная остановка).
- Кнопка «Тест» отправляет пробное сообщение в указанный чат (проверка настроек).

---

## 8. История измерений

- Экран **«История измерений»** на дисплее показывает список сохранённых измерений (дата, время, значения).
- Полный список и экспорт — через веб (`/api/measurements` и соответствующий раздел интерфейса).

---

## 9. Обновление прошивки (OTA)

- При использовании кастомной схемы разделов (например, `partitions.csv` из проекта) и включённой OTA: в браузере откройте **http://&lt;IP&gt;/update**, выберите файл прошивки (.bin) и загрузите.
- После успешной загрузки устройство перезагрузится с новой прошивкой. Первую прошивку после смены схемы разделов рекомендуется заливать через USB.

## 10. Краткая памятка

| Действие | Как сделать |
|----------|-------------|
| Переключить экран | Короткое нажатие кнопки |
| Открыть меню (START / RESET MOV / RESET ZERO / EXIT) | Длинное нажатие на экране 1–7 |
| Запустить программу Сжатие/Разрыв | Меню с экрана 1 или 2 → START → длинное нажатие |
| Остановить программу | Длинное нажатие кнопки во время работы |
| Сбросить ноль весов | Меню → RESET ZERO → длинное нажатие |
| Сбросить перемещение (MOV) | Меню → RESET MOV → длинное нажатие |
| Настроить Wi‑Fi, калибровку, программы, NTP, Telegram | Веб-интерфейс по IP устройства (порт 80) |
| Ручное управление мотором | Веб — кнопки Вверх/Вниз/Стоп |
| Обновить прошивку по воздуху | Веб — страница /update |
