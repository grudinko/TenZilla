✅ TTF файл найден: fa-solid-900.ttf

ШАГ 1: Откройте онлайн-конвертер LVGL
   https://lvgl.io/tools/fontconverter

ШАГ 2: Генерация шрифта 14px (для индикаторов WiFi/CPU/FPS)

   1. Нажмите "Choose File"
   2. Выберите: src/fonts/fa-solid-900.ttf
   3. Name: fontawesome_14
   4. Size: 14
   5. Bpp: 4
   6. Range: Добавьте по одному (после каждого нажмите Add):
      - 0xF0AA → Add
      - 0xF0AB → Add
      - 0xF1EB → Add
      - 0xF28D → Add
   7. Нажмите "Convert"
   8. Скачайте файл
   9. ЗАМЕНИТЕ файл: src/fonts/lv_font_fontawesome_14.c

ШАГ 3: Генерация шрифта 48px (для иконок двигателя)

   1. Повторите шаги из ШАГ 2, но:
      - Name: fontawesome_48
      - Size: 48
      - Те же Range
   2. ЗАМЕНИТЕ файл: src/fonts/lv_font_fontawesome_48.c

ШАГ 4: Включение шрифтов

   Откройте: src/TenZillaPins.h
   
   Найдите строки (около 118-119):
   // #define LV_FONT_FA14_ENABLED 1
   // #define LV_FONT_FA48_ENABLED 1
   
   Раскомментируйте (уберите //):
   #define LV_FONT_FA14_ENABLED 1
   #define LV_FONT_FA48_ENABLED 1

ШАГ 5: Пересоберите проект
